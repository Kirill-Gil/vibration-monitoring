# Система онлайн-мониторинга электродвигателей 0.4–6 кВ (ДНС)

Веб-приложение для мониторинга технического состояния агрегата по ГОСТ Р ИСО 20816, анализа спектров огибающей (дефекты подшипников) и MCSA токов статора.

---

## 🚀 Быстрый запуск (для новичков)

Перед запуском убедитесь, что на компьютере установлен **Python 3.10** или новее.
*(При установке на Windows обязательно отметьте галочку **«Add Python to PATH»**)*.

### На Windows:
1. Скачайте проект (нажмите зеленую кнопку **Code** -> **Download ZIP** вверху страницы и распакуйте архив).
2. Дважды кликните по файлу **`run_windows.bat`**.
3. Скрипт сам создаст окружение, установит библиотеки и откроет сайт в браузере.

### На macOS / Linux:
1. Откройте терминал в папке проекта.
2. Сделайте скрипт исполняемым и запустите его:
   ```bash
   chmod +x run_unix.sh
   ./run_unix.sh
